# Calendário Editorial & Planejamento

> **Para quem:** Social Media, Account (Lucas), Gestor. Produção usa a aba de Captações.

---

## TL;DR — 30 segundos

No dia 1º de cada mês, a IA já monta o calendário de todos os clientes. Você revisa, aprova e cada ideia pode virar roteiro com um clique. Aprovação mais rápida: vai pelo Meu Dia, não precisa abrir essa tela.

---

## Fluxo completo do conteúdo

```
Dia 1º do mês
  → IA gera o plano (automático)
  → Cai no Meu Dia como cartão 🗓️

Você aprova (Meu Dia ou aqui no Planejamento)
  → Tarefa criada pro Lucas levar o plano ao cliente

Cliente aprova o plano
  → Ideias viram roteiros (IA escreve)
  → Captação agendada (produção registra)
  → Edição entrega o vídeo
  → IA escreve a legenda
  → Gestor aprova legenda no Meu Dia (cartão ✍️)
  → Postagem
```

## Planejamento — calendário por cliente

**Acessar:** menu → Estúdio → **Planejamento**

### Selecionar o cliente
Seletor no topo → escolha o cliente. O calendário do mês carrega.

### Gerar o plano manualmente (se não gerou automático)
Botão **Gerar plano do mês** → a IA cria ideias para o mês inteiro em 30–60 segundos.

Cada ideia tem:
- Tema / título
- Formato (Reels, Carrossel, Story, YouTube Shorts)
- Melhor dia para postar
- Sugestão de gancho

### Revisar e ajustar ideias
- **Clique em ✏️ Editar** na ideia → muda título, formato ou data
- Arraste ideias entre dias para reorganizar o calendário
- Delete ideias que não fazem sentido

### Aprovar o plano
**Opção 1 (recomendada):** Meu Dia → cartão 🗓️ → **✓ Aprovar plano**
- Um clique, pronto
- Sistema cria tarefa pro Lucas apresentar ao cliente

**Opção 2:** Dentro do Planejamento → botão **Aprovar** em cada ideia ou **Aprovar tudo**

### Gerar roteiro a partir de uma ideia
1. Clique na ideia aprovada
2. Botão **Gerar roteiro**
3. Roteirista de IA escreve em segundos:
   - Gancho de abertura (3 primeiros segundos)
   - Desenvolvimento (o que mostrar e falar)
   - CTA (chamada para ação)
4. Edite o que quiser → copie para o produtor

## Produção — controle de captações

**Acessar:** menu → **Produção**

### Registrar uma captação realizada
1. Botão **+ Registrar captação**
2. Selecione o cliente
3. Informe a data e o tipo de conteúdo gravado
4. **Salvar**

O sistema atualiza o contador do cliente (ex.: Vivenda 2/4 captações no mês). Quando zera a meta, o alerta do Meu Dia some automaticamente.

### Ver o status de captações do mês
A tela de Produção mostra todos os clientes com:
- Contrato: X captações/mês
- Realizadas: Y no mês atual
- Status: verde (ok) / vermelho (em falta)

## Erros comuns

**Plano não foi gerado automaticamente no dia 1º**
Leva algumas horas. Se passou do dia 2: Planejamento → selecione o cliente → **Gerar plano do mês**.

**Aprovei o plano mas tarefa não foi criada pro Lucas**
A tarefa automática só é criada quando você aprova pelo **Meu Dia**. Se aprovou dentro do Planejamento, crie a tarefa manualmente nas Atividades.

**O roteiro saiu genérico / sem a voz do cliente**
O perfil do cliente está desatualizado. Edite o cadastro do cliente e adicione: segmento exato, tom de voz, produtos/serviços principais, diferenciais. Depois gere novamente.

**Captação registrada mas não apareceu no contador**
Confirme que o cliente selecionado na Produção é exatamente o mesmo do cadastro. Qualquer diferença no nome quebra o vínculo.

---

## Regra de ouro

> O plano aprovado no dia 5 = o mês inteiro de conteúdo organizado. Quanto mais tarde você aprova, menos tempo tem para ajustar antes das captações. Dia 5 é o deadline interno — não dia 20.
