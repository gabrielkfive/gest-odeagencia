# Tarefas & Kanban

> **Para quem:** Toda a equipe. Editores, account, design, produção — tudo o que fazemos vira tarefa aqui.

---

## TL;DR — 30 segundos

Kanban com 4 colunas: **Backlog → Em Andamento → Aprovação → Concluído**. Arrasta o cartão conforme avança. Filtra por seu nome para ver só o que é seu. Conclui no mesmo dia que entregou.

---

## As 4 colunas explicadas

| Coluna | O que significa | Quem move para cá |
|--------|----------------|-------------------|
| **Backlog** | Criada, não começou | Quem criou a tarefa |
| **Em Andamento** | Alguém está trabalhando | O responsável, ao começar |
| **Aprovação** | Pronto, esperando OK | O responsável, ao terminar |
| **Concluído** | Entregue e fechado | Quem aprovou |

**Regra simples:** você arrasta seu próprio cartão. Não mexa no cartão de outro sem combinar.

---

## Como usar

### Criar uma tarefa
1. Botão **+ Nova** (canto superior direito)
2. Preencha:
   - **Título** → seja específico: ❌ "Editar vídeo" ✅ "Editar Reels Vivenda — fondue — entrega quinta"
   - **Responsável** → nome exato como cadastrado no sistema
   - **Cliente** → selecione da lista
   - **Prazo** → data real de entrega (não a data que você vai começar)
   - **Prioridade** → Alta 🔴 / Média 🟡 / Baixa 🟢
   - **Função** → sua área (Edição, Account, Design, Tráfego…)
3. **Salvar**

**Atalho:** clique em **+ Adicionar cartão** direto na coluna para criar mais rápido.

### Mover uma tarefa
Arraste o cartão de uma coluna para outra. No celular, arraste devagar e aguarde o card "prender".

### Abrir o detalhe
Clique no cartão. Dentro você pode:
- Editar qualquer campo
- Adicionar checklist (subtarefas dentro da tarefa)
- Deixar observações / histórico

### Filtrar para ver só o que é seu
Barra de filtros no topo:

| Filtro | Para que usar |
|--------|--------------|
| 🔍 Busca | Achei uma tarefa pelo nome |
| Responsável | Ver só as minhas tarefas |
| Cliente | Ver tudo de um cliente específico |
| Prioridade | Ver só o urgente |
| ⚠️ Atrasadas | Minha lista de vergonha — zerar isso é prioridade |
| 📅 Hoje | O que vence hoje |

**Limpar filtros:** botão **✕ Limpar filtros** aparece quando há filtro ativo.

### Trocar de visão

| Botão | Melhor para |
|-------|-------------|
| ▦ Kanban | Operação do dia a dia |
| ☰ Lista | Ver tudo de uma vez, ordenado |
| 🗓️ Calendário | Planejar a semana / ver buracos no cronograma |
| 👥 Por Pessoa | Reunião de equipe — quem tem mais carga |
| 📊 Painel | Relatório de produtividade |

### Adiar atrasadas (emergência)
Botão **"Adiar atrasadas → amanhã"** no topo: move tudo que passou do prazo para amanhã. Use só quando o dia desandou por completo. Se você usa isso todo dia, tem problema de capacidade.

## Erros comuns

**Criei a tarefa mas sumiu do Kanban**
Tem filtro ativo. Clique em **✕ Limpar filtros** — ela aparece.

**Movi para Concluído mas some da tela**
Normal se estiver filtrado por "Atrasadas" ou "Hoje" — a tarefa foi concluída e saiu desse filtro. Limpe o filtro para ver tudo.

**Não consigo arrastar no celular**
Abra o cartão → mude o status manualmente dentro do modal (campo "Status").

**Tarefas da equipe desatualizadas**
Procure o indicador de sincronização no topo da tela. Aguarda ele mostrar "✓ Sincronizado". Se demorar, F5.

## Regra de ouro

> Concluiu a entrega? Arrasta para Concluído agora. Não existe "vou fechar depois". O KPI de concluídas hoje é o termômetro real da operação — e ele aparece no Meu Dia do Gabriel.
