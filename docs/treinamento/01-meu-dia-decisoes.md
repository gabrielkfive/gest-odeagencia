# Meu Dia & Decisões de Hoje

> **Para quem:** Todos da equipe — é a primeira coisa a abrir todo dia.

---

## TL;DR — o que você precisa saber em 30 segundos

O Meu Dia é sua mesa de trabalho. No centro fica a **fila de Decisões** — cartões do que o sistema já preparou e está esperando o SEU aval. Resolva os 🔥 primeiro. Quando a fila estiver zerada, aparece um troféu 🏆 — isso significa que a agência está operando bem.

---

## O que é a fila de Decisões de Hoje

A agência trabalha no piloto automático. Roteiros são gerados, tarefas são criadas, captações são monitoradas. Mas nada vai para o cliente sem um olho humano. A fila mostra só o que está parado esperando você.

**Cada cartão tem:**
- Ícone + cor (urgência)
- Nome do cliente
- O que está esperando
- Botões de ação direto no cartão — sem precisar abrir outra tela

**O que cada cor significa:**

| Ícone | Cor de fundo | O que é | Quem age |
|-------|-------------|---------|----------|
| 🔥 | Vermelho | Tarefa atrasada — já passou do prazo | Responsável pela tarefa |
| ⚡ | Amarelo | Tarefa vence hoje, prio alta | Responsável pela tarefa |
| 🎬 | Dourado | Roteiro pronto esperando aprovação | Gestor / Admin |
| ✍️ | Roxo claro | Legenda aguardando revisão | Gestor / Admin |
| 🗓️ | Verde | Plano mensal da IA esperando aval | Gestor / Admin |
| 📹 | Vermelho claro | Captação em falta no mês | Account (Lucas) |

**Cartões ordenados por urgência:** os 🔥 ficam sempre no topo.

## Como usar

### 1. Abrir o Meu Dia
Menu lateral → ícone de casa 🏠 **Meu Dia**

### 2. Resolver os cartões

Para cada cartão, você tem botões diretos:

- **✓ Concluir** → marca a tarefa como feita na hora
- **Adiar** → empurra para amanhã
- **Ver** → abre o detalhe completo
- **✓ Aprovar → captação** → aprova roteiro e já cria tarefa de gravação
- **Criar tarefa de agendar** → cria tarefa no nome do Lucas para contato com cliente

### 3. Ver a agenda do dia
Lado direito da tela (no celular: role para baixo). Eventos do Google Calendar do dia.

### 4. Consultar o JARVIS
O cartão escuro com a bolinha dourada é o resumo do assistente.
- Clique no cartão → conversa com o JARVIS
- Botão **🔊 JARVIS narra meu dia** → ouve o resumo em voz

## Erros comuns

**Fila vazia mas sei que tem coisa pendente**
Seu nome no sistema precisa ser exatamente igual ao campo "responsável" das tarefas. Menu → engrenagem ⚙️ → confira o nome cadastrado.

**JARVIS não aparece**
Aguarda 10–15 segundos após abrir — ele carrega depois do resto. Se nada aparecer, F5 na página.

**Aprovei um roteiro mas continua na fila**
Normal — o sistema sincroniza com a nuvem em alguns segundos. Aguarda e a fila atualiza sozinha.

**Agenda não mostra meus compromissos**
Ferramentas → Integrações → verifique conexão com Google Calendar.
