## O que cada cor de status significa

### Tarefas (no Kanban)
| Cor da bolinha | Status |
|---------------|--------|
| ⚫ Cinza | Backlog — não começou |
| 🟡 Amarelo | Em Andamento |
| 🔵 Azul | Aprovação |
| 🟢 Verde | Concluído |

### Clientes (na Lista de Clientes)
| Cor | Situação | Ação |
|-----|----------|------|

| 🔴 Vermelho | Crítico | Contato hoje, sem falta |

|-------|----------|---------|

| ⚡ | Alta | Vence hoje |

## Atalhos rápidos

| Ação | Caminho mais rápido |
|------|---------------------|
| Criar tarefa rápida no Kanban | Atividades → clique "+ Adicionar cartão" na coluna desejada |
| Aprovar plano mensal | Meu Dia → cartão 🗓️ → "✓ Aprovar plano" (sem abrir Planejamento) |
| Ouvir resumo do dia | Meu Dia → cartão JARVIS → 🔊 "JARVIS narra meu dia" |
| Enviar cobrança | Financeiro → Cobranças → "Abrir no WhatsApp" |
| Copiar Pix para pagar | Financeiro → Acerto → clica na chave Pix |
| Adiar tudo atrasado | Atividades → botão "Adiar atrasadas → amanhã" |
| Filtrar minhas tarefas | Atividades → filtro Responsável → seu nome |

## Erros mais comuns e solução rápida

| Problema | Solução |
|---------|---------|
| Tarefa sumiu do Kanban | Tem filtro ativo → clique **✕ Limpar filtros** |
| Não aparecem decisões para mim | Seu nome no sistema ≠ campo "responsável". Ajuste nas configurações ⚙️ |
| Nada sincronizando | F5 na página |
| Agenda sem eventos do Google | Ferramentas → Integrações → reconecte o Google Calendar |
| JARVIS responde de forma genérica | Seja mais específico na pergunta (cliente, data, área) |
| Plano mensal não foi gerado | Estúdio → Planejamento → cliente → "Gerar plano do mês" |
| Cliente não está nas cobranças | Cadastro incompleto → edite: tipo = ARK Direto + valor mensal |
