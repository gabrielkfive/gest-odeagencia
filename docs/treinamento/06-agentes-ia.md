# Agentes de IA

> **Para quem:** Todos. Cada área tem seus agentes. Gestor e Gabriel usam o Conselho.

---

## TL;DR — 30 segundos

Os agentes são funcionários digitais: trabalham sozinhos, deixam o resultado na fila e esperam o seu toque final. Você não opera eles — você aprova o que fizeram. O Conselho de IA debate a operação toda manhã e cria briefings estratégicos.

## Roteirista Viral — passo a passo

**Acesso:** menu → Estúdio → **Roteirista**

1. Selecione o **cliente** (ou informe o segmento manualmente)
2. Digite o **tema** do vídeo
   - Ex.: "bastidor da preparação do fondue de queijo — Vivenda"
   - Ex.: "dica rápida: como pedir a mesa certa num restaurante"
3. Escolha o **formato**: Reels / TikTok / YouTube Shorts
4. **Gerar roteiro** → pronto em 10–30 segundos

O roteiro vem com:
- **Gancho** — o que dizer nos primeiros 3 segundos para parar o scroll
- **Corpo** — o que mostrar e falar, passo a passo
- **CTA** — o que pedir pro espectador fazer no final

5. Revise, ajuste o que precisar
6. Copie e passe para o produtor ou cole no briefing de captação

## Legendas — passo a passo

**Acesso:** menu → Estúdio → **Legendas**

1. Cole o roteiro ou descreva o vídeo em 2–3 linhas
2. Informe o tom: formal, descontraído, premium, humor…
3. **Gerar legenda**

A legenda vem com:
- Gancho na primeira linha (para parar o scroll)
- Texto no tom da marca
- Hashtags relevantes
- CTA no final (ex.: "Salva esse vídeo", "Comenta aqui", "Link na bio")

4. **Aprovação:** a legenda vai para a fila do gestor no Meu Dia (cartão ✍️)
5. Gestor aprova → vai para o social media postar

## Conselho de IA — como funciona

**Acesso:** menu → Estúdio → **Conselho de IA**

### O que é
Todo dia de manhã, os agentes se "reúnem" e debatem a situação da agência:
- Clientes em risco
- Tarefas críticas
- Oportunidades de mês
- Alertas de produção

O resultado são **briefings estratégicos** e, às vezes, **tarefas criadas automaticamente**.

### Ver o resultado do Conselho
No Meu Dia → aparece aviso: *"Os agentes já trabalharam hoje: X debates do Conselho"*
→ Clique em **"Ver debates"** para ler os insights completos

### Disparar manualmente (se não rodou ainda)
1. Estúdio → Conselho de IA
2. Botão **Rodar agora**
3. Aguarde 2–3 minutos
4. Briefings aparecem no Meu Dia

## Como os agentes se encaixam no seu dia

```
Dia 1º do mês (automático)
  → Agente de Planejamento gera calendários de todos os clientes

Todo dia de manhã (automático)
  → Conselho de IA debate a operação → briefings no Meu Dia

Quando você acessa o Meu Dia
  → Você vê o resultado dos agentes na fila de Decisões
  → Aprova, ajusta ou descarta com um clique

Quando você precisa de algo específico
  → Abre o agente direto (Roteirista, Legendas, Proposta)
  → Pede o que precisa → revisa → usa
```

## Rotina por função

### 🎬 Social Media / Roteirista
```
Criar roteiros:
  Estúdio → Roteirista → cliente → tema → Gerar

Gerar várias numa tarde:
  → 5 temas em sequência → 5 roteiros em ~15 minutos

Criar legenda após a edição:
  Estúdio → Legendas → cola o roteiro → Gerar
```

### 👤 Gestor — aprovações
```
Todo dia:
  Meu Dia → cartão ✍️ legendas pendentes → "Revisar e aprovar"
  Meu Dia → cartão 🎬 roteiros pendentes → "✓ Aprovar"

Toda segunda:
  Conselho de IA → lê os briefings → define ações da semana
```

### 👤 Gabriel / Comercial
```
Proposta para novo lead:
  Central de Agentes → Estrategista Comercial
  → Informa segmento e perfil do lead
  → Proposta de 17 páginas em 1–2 minutos
  → Envia como PDF
```

## Erros comuns

**Conselho não rodou hoje**
Estúdio → Conselho de IA → **Rodar agora**. Acontece se o servidor não recebeu o sinal de início do dia.

**Roteiro ficou genérico / não combina com o cliente**
O perfil do cliente está raso. Edite o cadastro do cliente: segmento exato, produtos, tom de voz, diferenciais, público-alvo real. Gere novamente.

**Proposta demora muito para gerar**
Documentos complexos levam até 2 minutos. Não feche a tela — aguarde.

**Legenda foi para aprovação mas gestor não encontra**
O gestor precisa estar logado e ter perfil de gestor/admin. A legenda aparece no Meu Dia → cartão ✍️. Se não aparecer, verifique o perfil de acesso.

---

## Regra de ouro

> Os agentes fazem 80% do trabalho. Mas os 20% finais — o olhar humano, o ajuste de tom, o contexto que só você conhece — são o que separa um conteúdo bom de um conteúdo excelente. Revise sempre antes de aprovar.
